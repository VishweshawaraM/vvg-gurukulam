How to Make the Website Live

Step-by-step guide · So simple a child can follow
What does "Live" mean?
Right now, the website only works on your computer and the campus WiFi. "Live" means anyone, anywhere in the world can open it on their phone or laptop — even from home, even without being on campus WiFi.
Part 1 — Create a Free GitHub Account (5 minutes)
1
Open GitHub Website
GitHub is a free website where we store our code safely, like Google Drive but for websites.
→ Open: github.com
What to do: Click the big green button that says "Sign up"
2
Create Your Account
Fill in the form on GitHub:
1
Enter your email address (any Gmail works)
2
Create a password (write it down)
3
Choose a username like vvgurukulam
4
Click "Continue" and verify your email
3
Create a New Repository (Storage Folder)
After logging in to GitHub:
1
Click the "+" icon at the top right
2
Click "New repository"
3
Name it: vvg-gurukulam
4
Select "Private" (CRITICAL for Security! Do NOT select Public)
5
Click the green "Create repository" button
Write down your GitHub username. You will need it in the next step. Example: if you chose vvgurukulam, write that down.
4
Upload the VVG Code to GitHub
Go to the VVG Gurukulam project folder on your Desktop. Find the file called UPLOAD_TO_GITHUB.bat and double-click it.
A black window will open. It will ask:
"GitHub username:" — type your GitHub username and press Enter.

It will then automatically upload everything. Wait for it to say "Upload complete!"
Then press any key to close the window.
Part 2 — Deploy on Railway (Get a Public URL) — 10 minutes
5
Open Railway Website
Railway is a free hosting website. It takes your code from GitHub and makes it live 24/7. You do not need to keep your computer on.
→ Open: railway.app
Click "Login" at the top right → then click "Login with GitHub"
It will ask to connect your GitHub account → click "Authorize"
6
Create a New Project
1
Click the big "New Project" button
2
Click "Deploy from GitHub repo"
3
Select "vvg-gurukulam" from the list
4
Click "Deploy Now" — Railway will start automatically
Wait about 2–3 minutes. You will see a loading bar. When it turns green, it is ready!
7
Set the PORT Setting
Railway needs to know which port to use. Do this:
1
Click on your project → click "Variables" tab
2
Click "New Variable"
3
Name: PORT   Value: 3000
4
Click "Add"
8
Get Your Public Website URL
After deployment is complete:
1
Click "Settings" in your Railway project
2
Scroll down to "Domains"
3
Click "Generate Domain"
4
You will get a URL like: vvg-gurukulam.up.railway.app
This is your permanent website address!
Share this URL with all 14 Acharyas. They can open it on any phone or laptop, from anywhere in India, at any time — without campus WiFi.
Part 3 — Keep it Updated
9
Every time you make changes
Whenever something changes in the system (new students, new Acharya, etc.):
1
Double-click UPLOAD_TO_GITHUB.bat in the project folder
2
Wait for it to say "Upload complete!"
3
Railway will automatically update the live website within 2 minutes
That's it! You never need to do anything else. Railway watches GitHub and updates automatically.
If you get stuck at any step — take a screenshot and share it with the system administrator. Do not try to click random buttons on Railway or GitHub without guidance.
